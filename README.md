# Córrego Correntinho

Estudo ambiental da microbacia do Córrego Correntinho, Miracema do Tocantins (TO).

Visualização pública da evolução da cobertura do solo, 2011 a 2026: https://sribeiro950-arch.github.io/correntinho/

Elaboração: Aurelio Ribeiro dos Santos (2026), Engenheiro Ambiental e Sanitarista, CREA-TO 309875 D. Imagens: Landsat (USGS/NASA). Material técnico preliminar, sujeito à revisão do responsável.
